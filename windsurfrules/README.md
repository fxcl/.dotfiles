✨ Custom Windsurf Instruction Files ✨

📃 This repository contains custom instruction files (.windsurfrules) for Windsurf.

## 🚀 Usage
🛠️ Windsurf Project Configuration

1️⃣ 📁 Place the .windsurfrules file in your project's root directory.

2️⃣ ⚙️ Alternatively, from [Windsurf - Settings] at the bottom right of the window, click [Set Workspace AI Rules] and then [Edit Rules] to copy and paste the content of the .windsurfrules file.

3️⃣ 📋 Alternatively, paste the contents via [Windsurf - Settings] > [Cascade Memories Panel] > [Use Defined Rules] > [Edit workspace rules/Edit global rules].

⌨️ Select the relevant part and press Cmd+i (or Ctrl+i) to open and edit.

💡 Without reference files, update rules using language/framework-specific best practices.

🔄 Update specifications as your project evolves.

🎯 Custom instructions are most effective when combined with task-specific prompts and contextual reference materials.

## 📝 Notes
⚠️ Effectiveness decreases if content conflicts with the Global AI Rules. Review the Global AI Rules thoroughly.

✍️ Modify the contents as necessary to suit your project.

📏 The character limit for the .windsurfrules file is 6,000 characters.
