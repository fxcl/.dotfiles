# Project Brief

This repository contains the configuration for RooCode, a VS Code extension that provides AI-assisted coding capabilities.

## Core Mission

The primary goal of this project is to provide a centralized and version-controlled configuration for the RooCode extension, enabling consistent and customizable AI-driven development workflows across different environments.

## Core Requirements

*   **Maintainability:** The configuration should be easy to understand, modify, and extend.
*   **Modularity:** The rules and settings for different AI modes and features should be organized logically.
*   **Scalability:** The structure should support the addition of new modes, tools, and integrations without significant refactoring.
